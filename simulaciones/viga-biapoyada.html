Viga biapoyada

Biapoyada · q uniforme en [0, L] · P = qL en s = x
Resistencia de Materiales · caso resuelto · x = L/2
Convenio. s: coordenada desde el extremo izquierdo. q y P positivas hacia abajo. V(s) positivo: parte izq. empuja a la der. hacia arriba (giro horario del trozo aislado). M(s) positivo: tracciona la fibra inferior. Relación: dM/ds = V.

El caso

Viga simplemente apoyada de luz L. Carga uniforme q actúa en toda la viga. Carga puntual P = qL aplicada a distancia x del apoyo A (izquierdo).

Diagrama físico (DCL + reacciones + posiciones clave)

s = L/2

Planteamiento y cálculo

1. Reacciones (con x = L/2)

ΣMA = 0 (antihorario +)
RB·L − q·L·(L/2) − P·x = 0
RB·L = qL²/2 + qL·(L/2) = qL²
RB = qL
ΣFy = 0: RA + RB = qL + P = 2qL
RA = qL

Por simetría con x = L/2 ambas reacciones coinciden.

2. Leyes por tramos

Tramo 1: 0 ≤ s ≤ L/2

Fuerzas a la izquierda del corte: RA (↑) y la q acumulada q·s (↓).

V(s) = RA − q·s = qL − qs
M(s) = RA·s − q·s²/2 = qL·s − qs²/2

V(0) = qL  ·  V(L/2⁻) = qL/2  ·  M(0) = 0  ·  M(L/2) = qL²/2 − qL²/8 = 3qL²/8

Tramo 2: L/2 ≤ s ≤ L

Se añade la P (hacia abajo) a la izquierda del corte.

V(s) = qL − qs − P = qL − qs − qL = −qs
M(s) = qL·s − qs²/2 − qL·(s − L/2) = −qs²/2 + qL²/2

V(L/2⁺) = −qL/2  ·  V(L) = −qL  ·  M(L/2) = −qL²/8 + qL²/2 = 3qL²/8 ✓  ·  M(L) = 0 ✓

3. Verificación

  • Salto de V en s = L/2: V(L/2⁺) − V(L/2⁻) = −qL/2 − qL/2 = −qL = −P ✓
  • Continuidad de M en s = L/2: ambas ramas dan 3qL²/8 ✓
  • M(0) = M(L) = 0 (apoyos extremos sin voladizo) ✓

⚠ Error típico / Observación

Error típico: olvidar el salto −P en V en s = L/2. V pasa de +qL/2 a −qL/2, NO es continuo. M sí es continuo en ese punto (una carga puntual produce punto anguloso en M, no discontinuidad).
