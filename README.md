# Palanca

Apuntes propios, esquemas y simulaciones interactivas de Ingeniería Mecánica, gratis y abiertos.

**Web:** https://ricardoeee.github.io/palanca-web/

Empieza por Resistencia de Materiales: cortantes y flectores, tensiones tangenciales (Jourawski), flexión,
torsión y más. También hay simulaciones de mecanismos, materiales y ecuaciones diferenciales.

## Qué es

Una web personal y **no oficial**, hecha por un estudiante: lo que me habría gustado encontrar al estudiar.
Todo el contenido es propio o rehecho; no hay apuntes ni exámenes de profesores.

## Cómo está hecha

Web estática: React y Babel servidos desde el propio repo, sin build ni servidor. Para verla en local basta con
servir la carpeta, por ejemplo con `python -m http.server`.

Este repo solo contiene la web publicada, sin historial. Se genera desde un repo de trabajo privado.
